# Lumen Status

- Verifies financial calculations (DSCR, income, DTI)
- Recomputes values and compares against reported figures
- Flags mismatches and inconsistencies automatically
- Outputs confidence scores (pass / review / fail)
- Logs every check with evidence and timestamps
- Produces plain-English summaries for decisions

Current limitations:
- No UI (runs locally)
- Requires manual input of financial data
